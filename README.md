# GENeSYS-MOD | Guadeloupe Implementation

## Introduction
For general information about GENeSYS-MOD, please refer to the following resources:
- **GitLab**: [GENeSYS-MOD Public Repository](https://git.tu-berlin.de/genesysmod/genesys-mod-public)
- **Zenodo**: [GENeSYS-MOD Zenodo Community](https://zenodo.org/communities/genesys-mod/records?q=&l=list&p=1&s=10&sort=newest)

This repository contains the implementation of GENeSYS-MOD for Guadeloupe, including input data for three energy transition roads described in the paper titled *"The Road to a Sustainable Energy System in the Guadeloupe Archipelago: Challenges and Opportunities"*. The scenarios and their respective data files are outlined below.

---

## Scenarios and Input Data

1. **Baseline Transition Road**  
   Input data for the baseline scenario is available here:
